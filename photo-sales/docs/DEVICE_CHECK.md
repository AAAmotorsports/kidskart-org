# M3 実機確認チェックリスト (iPhone + 店内テレビ)

用意: iPhone (撮影に使う本人の端末)、受付のテレビに繋ぐ PC、お客様役のスマホ (別の端末)。写真は iPhone で 20〜100 枚撮影しておく。

## A. スタッフログイン (iPhone)
- [ ] Safari で `/admin/login` → メール入力 → メールが届く (迷惑メールに入っていないか)
- [ ] メールのリンクをタップ → 「ログインする」→ 管理画面が開く
- [ ] ホーム画面に追加してもログインが残る / 翌日も残っている (30 日)
- [ ] 別の人 (未登録のアドレス) では何も届かない / ログアウトできる

## B. 団体登録と QR
- [ ] 「団体登録」で 1 画面・10 秒以内に登録できる (開始時刻が現在時刻で入る)
- [ ] 同意の未チェックで赤い注意が出る (未成年・保護者同意の組み合わせも)
- [ ] 登録後に QR が出る。お客様役のスマホのカメラで読み取れる
- [ ] 「QR を大きく表示 / 印刷」から A4 に印刷できる、画面提示でも読み取れる

## C. 一括アップロード (★最重要)
- [ ] 「写真を選ぶ」→ ライブラリから 50〜100 枚をまとめて選べる
- [ ] 進捗バーが進み、完了までの時間は __ 分 (記録)。途中で iPhone が熱くならないか / Safari が落ちないか
- [ ] 画面が自動スリープしない (または暗くなっても続く)
- [ ] 機内モードを数秒入れて戻す → 失敗した枚数だけ「失敗した N 枚だけ再送」で送れる
- [ ] 同じ写真をもう一度選ぶと「重複」でスキップされる
- [ ] HEIC で撮った写真も取り込める (「設定 → カメラ → フォーマット」が「高効率」でも)
- [ ] 縦・横の向きが正しい。撮影順に並ぶ
- [ ] 写真を選択 → 削除 / 非表示 / 別の団体へ移動ができる

## D. お客様ページ (お客様役のスマホ)
- [ ] 公開前は「写真準備中」→ スタッフが「公開する」を押すと自動で写真が出る
- [ ] 写真をタップで拡大、左右スワイプ、♡で選択、枚数と金額が出る (1枚500 / 3枚1,000 / 5枚以上は全パック2,000)
- [ ] 透かしが見える。長押しで保存しても透かし入り
- [ ] 同意を外した団体のページは「公開されていません」になる
- [ ] (購入ボタンは M4 まで準備中表示)

## E. テレビ
- [ ] 管理画面「テレビ」の URL を PC のブラウザで開き、全画面にしてテレビに映す
- [ ] 写真が自動で切り替わる。新しい団体をアップロードすると優先して表示される
- [ ] 店内テレビの同意が無い団体は映らない
- [ ] 写真が 0 件のときロゴと案内が出る
- [ ] PC のネット回線を数分切っても表示が続き、復帰後に自動更新される
- [ ] 文字の大きさ・明るさ・案内文が店内で読める (気になる点をメモ)
