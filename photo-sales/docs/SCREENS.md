## スタッフ: グループ作成 (iPhone・1 画面)
```
┌ 新しい団体 ─────────────┐
│ 走行開始  [ 14:30 ]  (現在時刻)│
│ 団体名    [          ] 任意  │
│ 人数      [ − 5 + ]     任意  │
│ プラン    (レンタル)(レースパック)(他) │
│ ── 同意 (受付で案内して確認) ──   │
│ ☑ 写真撮影                      │
│ ☑ 販売ページへの掲載            │
│ ☐ 店内テレビへの表示 (別)       │
│ ☐ 未成年者を含む                │
│    └ ☐ 保護者の同意を得た       │
│ [ 作成してQRを表示 ]            │
└─────────────────────────┘
```
* 「販売ページ掲載」が OFF、または未成年で保護者同意が無い場合: 画面に
  「このグループの写真は**販売ページに公開されません**」を赤字で明示。アップロード自体は可能
* 作成直後に QR 画面 (画面提示 / 印刷)。同意は後から編集可 (変更は監査ログに記録)

## スタッフ: アップロード (グループ詳細)
```
[ 写真を選ぶ (最大 300 枚) ]
進捗  ██████░░░░ 62 / 100   ✅58  ⏳4  ❌3
画面を開いたままにしてください
[ 失敗した 3 枚だけ再送 ]   ← 最優先機能
```
* 選択後は自動で 3 並列処理 (原本再エンコード→プレビュー→サムネ→R2 直送→登録)
* 失敗は写真ごとに状態を保持 (成功済みは再送しない)。SHA-256 で重複スキップ
* 完了後: 撮影順グリッド。複数選択 → 削除 / 別グループへ移動 / 非表示。公開/非公開トグル、TV に表示

## お客様 `/g/{token}`
```
[ロゴ]  11/11 14:30 走行
─────────────────
 ▢▢▢   写真グリッド (3列、15秒毎に自動更新)
 ▢▢▢   準備中は「写真準備中です。しばらくお待ちください」
─────────────────
(下部固定) 3枚選択中 ¥1,000  [購入へ]
 * 5枚以上は「全写真パック ¥2,000 がお得」と表示
 * 購入済みの写真は ✓ 購入済み (選択不可)
購入前: メールアドレス入力 → Stripe Checkout
注意書き: QRを持つ方は閲覧できます。SNS等に公開しないでください
公開不可グループ / 期間終了: 「この写真は公開されていません」(理由は出さない)
```

## TV `/tv/{token}`
* `tv_ok` のグループのみ。最新アップロード優先、`group_seconds` ごとに次の団体へ
* 1 枚ずつ `slide_seconds`。ロゴ・団体名/走行時間・「QRで購入」案内。透かし・低解像度のみ
* 0 件ならロゴ+案内。通信断はキャッシュで継続し、復帰後に自動更新

## スタッフ: 売上・購入状況 (`/admin/sales`)
* 日別/月別売上、プラン別、グループ別、決済状況、CSV
* **購入率**: 公開グループのうち 1 件以上購入があった割合 (10/20/30% の見込みと比較)
* **全写真パック分析**: パック購入数・比率・グループ別 売上/人数 (`v_group_sales.revenue_per_head_jpy`)
* **要確認注文** (`needs_review`: 二重決済・金額不一致) を最上部に警告表示 → 確認して返金

## 要確認 (二重決済) の管理フロー
`/admin/orders` に赤バッジ。詳細で理由を表示し「全額返金」ボタン → Stripe Refund → 注文 `refunded`、
写真は再び購入可能。購入者へ返金メールを送る。
